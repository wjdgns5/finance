# 금융 데이터·계산 기준 — 0.6.0

제공된 프로젝트 문서와 2026-11-17 사용자가 승인한 BPS 기준을 실제 구현에 맞춰 정리했습니다. **공식과 계산 기준의 정의는 이 문서5.3을 기준**으로 합니다. 다른 문서는 이 표를 참조합니다. Phase7에서 금융 정책을 변경하지 않았습니다.

## 5.1 보존하는 메타데이터

기업명·종목코드·DART 고유번호, 사업연도·보고서 종류·연결/별도, 접수번호·공시일·실제 기간·출처·수집 시각을 보존합니다. 표준 계정에는 원본 계정 ID·이름·상세·금액 문자열을 연결합니다. 재무 스냅샷에는 재무·기간·주식수·공시 식별정보 원본 JSON과 정규화 경고를 저장합니다.

주식수는 결산일·공시 접수번호를, 시세는 보통주 종가·시가총액 각각의 기준일·출처를 보존합니다. 응답 meta와 data.shares에서 추적할 수 있습니다. API 키·요청 헤더·전체 요청 URL은 원본 증거에 저장하지 않습니다.

## 5.2 정규화·기간 선택

연간 사업보고서11011만 사용합니다. 같은 연도는 연결CFS 우선, 자료가 없을 때 별도OFS입니다. 인증 실패·호출 제한을 CFS 없음으로 해석하지 않습니다. 최신 확인 공시 연도부터 이전4년 범위를 수집하며 없는 연도를 과거 값으로 채우지 않습니다.

각 연도는 해당 연도 보고서의 당기 금액을 사용합니다. 전기·전전기 필드는 원본으로 보존하되 후속 보고서의 재작성 비교값으로 과거 연도 계정을 자동 덮어쓰지 않습니다. 공시 목록과 재무 응답의 최신 접수번호가 다르면 DART_REVISION_PENDING으로 처리합니다.

계정 매핑·기간·보통주 범위가 불확실하면 추정하지 않습니다. 서로 다른 연결/별도 범위는 같은 차트에 혼합하지 않고 기준이 다른 비교 계산은 N/A입니다. 사업연도는 실제 공시 기간과 종료연도로 판단하며 결산월을 화면에 표시합니다.

## 5.3 지표 기준표

모든 지표는 원화KRW, 해당 연간 기간·연결/별도·단위·필수 계정이 확인되어야 합니다. 필요한 근거가 부족하거나 비정상이면 아래 조건과 함께 N/A로 처리합니다.

| 코드·지표 | 공식·사용 계정·기준 | 주요 N/A 조건 |
|---|---|---|
| REVENUE_GROWTH·매출액 증가율 | (당기매출−직전연도매출)÷직전연도매출×100. 같은 연결/별도·겹치지 않는 기간 | 바로 전 연도 없음, 전기매출≤0, 기준 변경·기간 불일치 |
| OPERATING_MARGIN·영업이익률 | 영업이익÷매출액×100 | 매출≤0 |
| NET_MARGIN·순이익률 | 당기순이익÷매출액×100 | 매출≤0 |
| ROE | 지배주주 귀속 순이익÷기말 지배주주 지분×100. 별도에서도 이 계정 기준 유지 | 지분≤0, 해당 계정 없음. 자본총계로 대체하지 않음 |
| ROA | 당기순이익÷기말 자산총계×100 | 자산≤0 |
| DEBT_RATIO·부채비율 | 부채총계÷자본총계×100 | 자본≤0, 부채가 음수인 비정상 입력 |
| EPS | 공시된 보통주 기본주당이익 그대로. 직접 계산·추정 없음 | 공시값 없음·기본/보통주 범위 미확인 |
| BPS | 확인된 보통주 귀속 순자산÷같은 결산일 유통보통주식수(자기주식 제외). 우선주 미발행 확인 기업에 한해 CFS는 지배주주 지분, OFS는 자본총계 사용 | 우선주 발행·미발행 확인 불가, 주식수·기준일·공시 근거 부족 또는 불일치 |
| PER | 확인된 보통주 종가÷공시 EPS. 최근 사업연도와 별도 주가 기준일을 함께 표시 | EPS≤0·N/A, 종가·기준일·출처 부족 또는 비정상 |
| PBR | 확인된 보통주 종가÷반올림 전 BPS. 구현은 종가×유통보통주식수÷보통주 순자산으로 중간 반올림 회피 | BPS≤0·N/A, 종가·기준일·출처 부족 또는 비정상 |

BPS는 회사의 우선주 미발행 확인과 해당 공시 주식수의 우선주0을 모두 요구합니다. 유통보통주식수는 양수이고 같은 결산일의 접수번호 근거가 있어야 합니다. 발행·자기주식수가 함께 있으면 차감 결과와 유통주식수가 맞는지도 확인합니다. 유통주식수가 없을 때 발행주식수로 대체하거나 임의 역산하지 않습니다. 우선주 몫을 근사 배분하지 않습니다.

EPS와 BPS 자체의0·음수는 확인된 수치이면 AVAILABLE로 보존합니다. 이를 분모로 사용하는 지표의 산출 가능 여부는 별도로 판정합니다. 필요한 자료가 없는 경우 숫자0을 만들어 대신하지 않습니다.

### 화면에 사용하는 용어

ROE는 지배주주 기준, EPS는 공시된 보통주 기본주당이익, BPS는 보통주 기준입니다. ROE·ROA는 평균 자본/자산을 쓰지 않는 **기말 기준**입니다. PER·PBR은 표시한 재무 연도와 주가 기준일이 서로 다를 수 있으며 최근 사업연도 실적이 오래되었을 수 있습니다.

지표에는 공식·사용 계정·쉬운 설명·N/A 조건·기준 안내를 반환합니다. 최신 지표10개와 별도로 차트 이력 API는 각 연도의 영업·순이익률2개만 같은 엔진으로 계산합니다. 과거 연도 PER·PBR을 만들지 않습니다.

## 5.4 정밀도·표시 단위

계산은 BigDecimal이며 계산 결과는 소수6자리 HALF_UP입니다. 공시 EPS는 입력 정밀도를 보존합니다. 원본 계정과 중간 계산을 화면 표시 때문에 반올림하지 않습니다. 매우 작은 양수 BPS가 응답에서0.000000으로 표시되어도 PBR은 반올림 전 값으로 판정합니다.

금액·지표·주식수는 JSON 문자열, N/A 값은 null입니다. PERCENT의15.000000은15%이며 다시100배하지 않습니다. EPS·BPS는 KRW_PER_SHARE, PER·PBR은 TIMES입니다. 외화 환산은 지원하지 않습니다.

화면은 원 단위를 억 원으로, 지표를 읽기 쉬운 자리수로 표시합니다. 표·툴팁에 원본 문자열을 연결하고 그래프 좌표만 Number 근사값을 사용합니다. 금융 공식을 프론트엔드에서 다시 계산하지 않습니다.

## 5.5 상태·기준일·갱신

| 상태 | 의미 |
|---|---|
| AVAILABLE | 근거가 확인된 수치. 실제0·음수도 포함 |
| NOT_COLLECTED | 필요한 계정·EPS·시세·주식수·확인 정보 부족 |
| NOT_APPLICABLE | 기준 변경·비양수 분모·우선주 발행·비정상 입력 등으로 산출 불가 |
| UNSUPPORTED | 공통 enum에 유지. 금융업 재무·지표는 배열 대신422 오류 응답 |

각 지표는 status·reasonCode·한국어 reason을 반환합니다. 여러 결측이 겹치면 검사 순서에 따라 사유 한 개가 나옵니다. PER·PBR은 종가부터 검사하므로 종가도 없으면 MISSING_PRICE가 먼저 나옵니다. 시세가 없다는 이유로 나머지8개 지표를 차단하지 않습니다.

지표는 요청 시 계산하고 DB에 저장하지 않습니다. 일반 조회는 저장된 자료를 재사용하며 최신성 자동 보장은 없습니다. meta.stale은 마지막 수집 실패 이력입니다. false가 최신 거래일·정정본 반영을 뜻하지 않습니다. 명시적 sync 결과는 재무·시세 outcomes를 각각 확인해야 합니다.

## 5.6 알려진 제한

- 금융업 미지원. 업종코드64·65·66 계열은 재무 구조가 달라 안내합니다.
- 연간만 지원. 분기·반기·TTM을 혼용하지 않습니다.
- ROE·ROA 기말 기준. 평균 자본·평균 자산 지표는 구현하지 않았습니다.
- 우선주 발행 기업의 BPS·PBR은 엄격히 N/A. 보통주 몫을 근사 계산하지 않습니다.
- 공시 기본 EPS가 없거나 보통주 범위가 확인되지 않으면 EPS·PER N/A입니다.
- 주식 분할·무상증자 등으로 과거 EPS 비교가 단절될 수 있습니다. 이를 자동 보정하지 않습니다.
- 후속 보고서의 재작성 전기값을 과거 스냅샷에 자동 반영하지 않습니다.
- 저장 시세는 실시간 가격이 아닙니다. 보통주 종목 범위의 시가총액이며 우선주를 합한 기업 전체 시가총액이 아닙니다.
- 사용자 공시 화면 직접 대조는 미확인입니다. 실제 API 호출·자동 정규화·계산 테스트와 구분합니다.

## 5.7 검증 근거와 실제 사례

가상 정상·손실·우선주·자료 부족 기업으로 정책을 검증했습니다. 독립 기대값은 [계산 기대값](phase-3-expectations.md)과 테스트CSV에 보존합니다. Phase6에서는 실제 MySQL 포함 백엔드217개, 프론트엔드21개 테스트 및 브라우저15개 시나리오가 통과했습니다.

실제 DART 샘플68개 테스트는 원본→정규화→계산을 확인합니다. 삼성전자는 보통주 범위를 확정하지 못한 원본 기본 EPS를 임의 채택하지 않아 EPS·PER N/A를 유지합니다. 롯데케미칼의 과거 보고서 당기값과 후속 보고서 전기값 차이는 각 연도 보고서 기준 정책으로 보존합니다. 자세한 수치와 사용자 확인란은 [3종목 대조표](live-verification-table.md)를 참조하세요.

이는 수집한 응답과 구현의 검증입니다. 사용자 공시 원문 대조나 투자 판단을 대신하지 않습니다.
