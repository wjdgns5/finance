# 실제 공시 3종목 대조표 — 미수행

대상은 일반 제조업·적자·우선주 발행 기업 각 1개입니다. 모두 실제 **보통주 종목코드**로 조회합니다.
적자 여부와 우선주 발행 여부는 선택한 사업연도의 실제 공시에서 확인합니다.
실제 API 검증은 완료했고 기업·수치·공시 링크를 [대조용 표](live-verification-table.md)에 준비했습니다.
사용자가 직접 대조하지 않아 이 문서는 완료 증거가 아닌 실행 체크리스트로 유지합니다.

## 대조 순서

1. financials의 meta.mode=REAL, 대상 기업·회계연도·연결/별도·결산 기간을 확인합니다.
2. meta.financialPeriods의 receiptNo로 DART 공시를 엽니다.
   주소 형식: `https://dart.fss.or.kr/dsaf001/main.do?rcpNo=접수번호`.
3. 공시 화면의 표시 단위가 원·천원·백만원 중 무엇인지 확인하고 API 저장값의 원 단위와 맞춥니다.
4. 표의 매출·영업이익·순이익·공시 기본 EPS를 각각 원본 계정 ID·이름·상세·금액과 대조합니다.
   보통주/우선주와 기본/희석을 구별합니다. 기본 EPS가 없으면 추정값 대신 N/A인지 확인합니다.
5. 현재 연도 응답의 전기값이 과거 연도 저장값을 덮어쓰지 않았는지 확인합니다.
6. 최신 정정 공시와 financials의 접수번호를 대조합니다. API가 아직 이전 접수번호이면 새 값으로 확정하지 않습니다.
7. 지표를 [금융 기준표](financial-policy.md)에 따라 손계산 또는 별도 시트로 계산해 API와 비교합니다.
   기대값은 API 계산값을 복사해 만들지 않습니다.
8. 적자 기업의 음수 EPS 자체가 보존되는지, EPS ≤ 0이면 PER이 N/A인지 확인합니다.
9. 우선주 발행 기업의 BPS·PBR이 N/A + PREFERRED_SHARES인지 확인합니다. 공시가 불명확하면 확정하지 않습니다.
10. 시세가 없는 경우 재무 기반 지표가 유지되는지, 연결/별도 변경 구간의 증가율이 N/A인지 확인합니다.
11. sync 전후 기업·연도·계정이 중복되지 않는지와 수집 시점·접수번호 변화를 확인합니다.
12. 차이가 있으면 위의 표와 error.code·원본 계정 정보를 공유합니다. 인증키는 포함하지 않습니다.

실제 5개년·정정본 접수번호·전기 비교 필드·주식수·시세·9월 결산 기간은 자동 확인했습니다.
삼성전자 일반 기본 EPS 행의 보통주 범위는 미확정이며, 공시 화면의 EPS 주석을 직접 확인해야 합니다.
사용자 공시 화면 대조 결과는 아직 받지 않았습니다.
