# Phase 3 사전 기대값

계산 엔진 작성 전에 고정한 입력과 기대값입니다. 테스트 기대값은 계산 엔진을 호출해 생성하지 않습니다.
숫자 결과가 없는 사례의 예상 상태·사유도 CSV에 사전 기록했습니다.

기본 입력: 당기 매출 1,200, 전기 매출 1,000, 영업이익 180, 순이익 120,
지배주주 순이익 90, 지배주주 지분 600, 자산 1,500, 부채 700, 자본 800,
공시 기본 EPS 30, 종가 90, 발행 보통주 100, 자기주식 10, 유통 보통주 90, 우선주 0.
재무·주식수 결산일은 모두 2025-12-31이며 연결 재무제표입니다.

| 지표 | 사전 기대값 | 검산 요점 |
|---|---|---|
| 매출액 증가율 | 20% | 1,000에서 1,200으로 증가 |
| 영업이익률 | 15% | 매출의 15%가 180 |
| 순이익률 | 10% | 매출의 10%가 120 |
| ROE | 15% | 지배주주 지분의 15%가 90 |
| ROA | 8% | 자산의 8%가 120 |
| 부채비율 | 87.5% | 자본의 87.5%가 700 |
| EPS | 30 | 제공된 공시값 그대로 |
| BPS | 6.666667원/주 | 원값 6과 2/3, 최종 6자리 반올림 |
| PER | 3배 | EPS의 3배가 종가 |
| PBR | 13.5배 | 반올림 전 BPS의 13.5배가 종가 |

테스트 원본: `src/test/resources/metric-expectations.csv`, 10개 지표 × 6개 상황 = 60행.

- NORMAL: 위 입력 그대로.
- NEGATIVE: 해당 지표의 주요 입력을 음수로 변경. 음수 EPS·이익·BPS는 원값을 보존하고,
  PER/PBR의 비양수 분모와 음수 부채총계 등 잘못된 입력은 N/A로 판정합니다.
- ZERO: 주요 입력이 0인 사례. 실제 0을 결측으로 취급하지 않습니다.
- NULL: 필요한 계정의 값이 null인 사례.
- INSUFFICIENT: 전기·필수 계정·공시값 상태·주식수·시세가 부족한 사례.
- INVALID: 기준 변경, 0 이하 분모, 계정 단위 오류, 0 주식수·음수 종가 사례.

각 행은 지표별 독립 사례입니다. 예를 들어 ZERO의 증가율은 당기 매출을 0으로,
ZERO의 영업이익률은 영업이익만 0으로 바꾸고 매출은 기본값으로 유지합니다.
NEGATIVE도 해당 지표의 분자(또는 EPS/BPS 원값)를 음수로 바꾸며 나머지 입력은 유지합니다.

추가 독립 검산 사례: 지분 1, 유통 주식수 3, 종가 1의 PBR은 정확히 3입니다.
반올림한 BPS 0.333333을 재사용하면 생기는 오차를 허용하지 않습니다.

2026-11-17 사용자 확인: 우선주 미발행이 확인된 기업에 한해 BPS를 계산합니다.
연결은 지배주주 지분, 별도는 자본총계, 주식수는 같은 결산일의 자기주식 제외 유통 보통주를 사용합니다.
