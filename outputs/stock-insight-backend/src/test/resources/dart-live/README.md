# 실제 OpenDART 응답 샘플

2026-11-17 사용자 설정 인증키로 실제 조회한 응답입니다. 가상 계약 자료와 구분합니다.
기아(000270), 롯데케미칼(011170), 삼성전자(005930)의 2024·2025년 CFS 원본을 사용합니다.
정규화 전 financials·periods·shares 응답과 공시 목록의 filing 식별정보를 보존했습니다.
요청 URL·헤더·인증키는 저장하지 않았습니다. docs/live-samples에는 2021~2025년 수집 증거가 있습니다.

- normalization-expectations.csv: 원본에서 별도로 기록한 36개 계정 기대값.
- metric-expectations.csv: Java 엔진과 독립적인 BigInt 유리수 계산으로 산출한 30개 기대값.
- LiveDartSamplesTest: 정규화 36개, 계산 30개, 동일 IS/CIS 순이익 중복·상충 검사 2개, 총 68개.

삼성전자의 원본 기본 EPS 6605는 보통주 범위를 확정하지 못해 계산 입력으로 채택하지 않습니다.
우선주 발행 사실은 확인되어 BPS·PBR은 엄격하게 N/A입니다.
동일 표준 계정이 IS·CIS에 함께 표시되는 경우 ID·이름·상세·금액이 모두 같은 한 쌍만 IS를 선택합니다.
상충하는 값이나 같은 표 안의 중복은 여전히 미매핑입니다.

참조 접수번호: 기아 20260312001224 / 롯데케미칼 20260312001296 / 삼성전자 20260310002820.
이는 실제 API 원본 검증이며 사용자 공시 화면 직접 대조 완료를 뜻하지 않습니다.
