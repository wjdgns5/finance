0.6.0 구현 기준입니다. ADR은 설계의 이유와 대안을 남기는 기록입니다. 아래 항목은 채택한 결정이며 향후 개선은 별도로 표시합니다. 금융 계산의 공식·기준은 [금융 정책5.3](../stock-insight-backend/docs/financial-policy.md#53-지표-기준표)에서 정의합니다.

## 현재 한계와 다음 판단

실제 수집 메서드의 synchronized는 단일 로컬 사용에 맞는 선택입니다. 동시 사용자 증가 시 병목을 측정한 뒤 기업별 수집 잠금·작업 큐를 검토합니다. 현재 성능 향상 수치나 부하 시험 결과는 없습니다.

최신 거래일 자동 갱신·재작성 전기값 자동 반영·평균 자본/자산 지표·분기/TTM·우선주 근사 계산은 구현하지 않았습니다. 변경하려면 정책과 기존 결과의 영향을 먼저 검토해야 합니다.

사용자의 실제 공시 대조는 미확인입니다. 자동 정규화 테스트·브라우저 성공을 공시 원문 사용자 검증이나 투자 판단 검증으로 확대하지 않습니다.
